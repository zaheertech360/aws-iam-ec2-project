AWS IAM & EC2

Project Overview

This project demonstrates practical learning of AWS Identity and Access Management (IAM) and Amazon EC2.

Learning Objectives

  • Create IAM users, groups and policies.
  • Understand least privilege.
  • Launch an EC2 instance.
  • Configure Security Groups.
  • Install a web server.
  • Deploy a basic HTML website.

Tools & Technologies

AWS | IAM | EC2 | Linux | HTML

Project Status

Practical implementation in progress.
