
# AWS IAM & EC2

## Project Overview
This project focuses on learning and practicing
AWS Identity and Access Management (IAM) and
Amazon EC2.

## Learning Objectives
- Create IAM users and groups.
- Understand IAM policies and permissions.
- Apply the principle of least privilege.
- Launch and configure an EC2 instance.
- Configure EC2 Security Groups.
- Install a web server.
- Deploy a basic HTML website.

## Tools and Technologies
- Amazon Web Services (AWS)
- AWS IAM
- Amazon EC2
- Security Groups
- Linux
- HTML
